## Features

- **Responsive Design** — Optimized for desktop, tablet, and mobile screens.
- **Modern UI** — Clean layout with a dark-themed aesthetic.
- **Projects Showcase** — Dedicated space to explore my projects and experiments.
- **Social Links** — Quick access to my professional and social profiles.
- **Smooth Animations** — Interactive elements and animations for a polished experience.
- **Performance-Focused** — Built with a modern frontend stack.

## Tech Stack

- **Framework:** React with TanStack Start
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** CSS
- **Deployment Runtime:** Nitro with Cloudflare Workers support

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/omsharma1905/Simple-PortFolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Simple-PortFolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

Build the project for production:

```bash
npm run build
```

To preview the production build using the project's configured Cloudflare Workers environment:

```bash
npm run preview
```
